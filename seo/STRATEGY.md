## 何で1位を取るか

### 主戦場: サロン × AI電話（`salon-ai-phone` クラスタ）

「美容室 電話 自動化」「施術中 電話 対応」「一人サロン 電話 対応」など。

- 競合が弱い。大手SaaSはこの粒度の記事を書かない
- 検索している人がそのまま見込み客（MOYO Call が解ける課題そのもの）
- 既存11記事の軸と一致しているので、**新規作成より既存の拡充が効く**

ここは**取れる**。1位を狙うのはこのクラスタ。

### 面を広げる: AI電話代行 全般（`ai-phone-general` クラスタ）

「AI電話代行 比較」「AI電話代行 料金 相場」など。

検索volumeは大きいが、Salesforce・比較メディア・アフィリエイトサイトが上位を固めている。
**短期で1位は取れない**。ここは「比較・料金・仕組み」の網羅性で3〜10位に入り、
サロンクラスタから流入と被リンクを育ててから押し上げる中期戦。

### 追わないもの

- **単独の「MOYO」**: 日本では既に衣料・文具の MOYO ブランドが EC で面を取っている。
  異業種なので実害は無いが、この語で1位を取りに行くのは費用対効果が悪い。
  狙うなら「MOYO 電話」「MOYO サロン」「MOYO Call」の複合語。
- **地域名の量産**（「美容室 電話代行 渋谷」等）: 中身の無いページが量産されるだけで、
  現在の記事密度では逆効果。主戦場で1位を取ってから検討する。

## ドメインの方針（2026-08-31 決定）

**MOYO Call は `call.moyo.tokyo` へ集約する（2026-08-31 確定）。** ブランドは MOYO で確定しており、
`moyo.tokyo` は既に稼働している（`survey.moyo.tokyo` = MOYO Condition／サーベイ）。
`callmintai.com` は主要KWで圏外＝積み上がったドメイン評価が事実上ゼロなので、
**移行コストが最も安いのが今**で、記事が増えるほど高くなる。

### 移行の手順

コード側は1コマンドで終わる。落とすと評価が消えるのは 2 と 3。

```sh
# 1. ページ内の絶対URL・構造化データ・llms.txt・keywords.json を一括書き換え
python3 tools/seo_fix.py --migrate-domain          # 下ごしらえの確認だけ
python3 tools/seo_fix.py --migrate-domain --yes    # 実行
python3 tools/seo_fix.py            # sitemap / robots を新ドメインで再生成
python3 tools/seo_audit.py --strict  # canonical の不整合が 0 件になることを確認
```

2. **旧URL → 新URL を1対1で 301**。`callmintai.com/blog/xxx/` → `call.moyo.tokyo/blog/xxx/`。
   **トップにまとめてリダイレクトしない**（評価が渡らず、実質やり直しになる）
3. **Search Console で新プロパティを登録し、アドレス変更ツールを使う**。
   これを省くと、Google が別サイトとして扱い直すまで数ヶ月かかる
4. `GSC_SITE_URL` の secret を新プロパティへ差し替える（日次エージェントの参照先）
5. **旧ドメインは最低2年維持する**。切ると 301 が消えて評価が落ちる
6. cms（`app.callmintai.com`）・メール・Twilio・Stripe の参照は別途。
   手順書は `callmint-cms/docs/2026-08-18-moyo-domain-migration-plan.md`

### 決まったこと・残っていること

- ~~サブドメインかパスか~~ → **`call.moyo.tokyo`（サブドメイン）で確定**。
  survey が `survey.moyo.tokyo` なので運用を揃える。SEO 上はパスのほうが
  moyo.tokyo 本体の評価を共有できるぶん有利だが、その差より運用の一貫性を取った。
  サブドメインは別サイト扱いになりうるので、**moyo.tokyo 側から call.moyo.tokyo へ
  相互にリンクを張る**ことで補う
- **移行のタイミング**。記事の拡充が一巡してからにする（移行直後は順位が
  一時的に揺れるため、揺れと施策の効果が混ざると何が効いたか判断できなくなる）

### 順番を間違えるとインデックスから落ちる

DNS も 301 も無いうちに canonical を新ドメインへ向けると、Google は
「存在しない正規URL」を見ることになる。復旧に数ヶ月かかるので、
`--migrate-domain` は **`--yes` を付けないと書き換えない**ようにしてある。
`--yes` 無しで実行すると、先に済ませるべき3点（DNS・1対1の301・
Search Console のプロパティ登録）だけが出る。

なお `support@callmintai.com` のようなメールアドレスは URL ではないので
自動では書き換えない。新ドメインのメールボックスを用意してから手で直す
（移行スクリプトが残っているファイルを名指しする）。

### 単独の「MOYO」は追わない

日本では既に衣料・文具の MOYO ブランドが EC で面を取っている。異業種なので実害は無いが、
この語で1位を取りに行くのは費用対効果が悪い。狙うのは「MOYO 電話」「MOYO サロン」
「MOYO Call」の複合語。

## 1位までの道筋

| 段階 | やること | 目安 |
|---|---|---|
| 済 | 技術SEOの欠陥を潰す（画像29MB・meta欠落・構造化データ・sitemap） | — |
| **次** | **Search Console を接続する**（`GSC_SERVICE_ACCOUNT_JSON`）。これが無いと順位が見えず、エージェントは自サイトの欠陥しか見られない | 即 |
| 1〜2ヶ月 | 既存11記事を1本ずつ 6,000〜10,000字へ拡充（日次エージェントが1日1本） | 自動 |
| 2〜4ヶ月 | サロンクラスタの未作成6記事を作る | 自動 |
| 3ヶ月〜 | 被リンク。ここだけは自動化できない（下記） | 手動 |

### 自動化できない打ち手（人間がやる）

順位の上限を決めるのは最終的に**外部からの評価**で、これはコードでは作れない。

- **導入事例を増やす**。現在2件（BONHEUR HAIR / ZiL 亀有）。事例ページは被リンクと
  E-E-A-T の両方に効く。ただし **公開してよい成果の数字はまだ無い**（過去に載っていた
  「100% / 0件 / 1日」は実測ではなかったため削除済み）。数字を出すなら、サロンから
  実測値の掲載許可を取るところから始める
- **サロン向けメディア・美容商材の展示会・地域の美容組合**からの掲載/リンク
- **Google ビジネスプロフィール**（合同会社8ZERO として）
- note / X で書いている内容から、LP の該当記事へ導線を張る
  （`callmint`リポジトリの content-shark が週次で note 記事を作っている。
  そこから LP へリンクしていないのは機会損失）
- 「MOYO Call」で**実際に電話をかけたレビュー**を書いてもらう
