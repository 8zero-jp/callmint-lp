# MOYO SEO 戦略

> 正本。方針を変えたらこのファイルを直す。日次エージェント（`tools/seo_daily.mjs`）は
> `seo/keywords.json` を読んで動くので、**狙う先を変えるときは keywords.json も直す**。

| | 状態 |

## 何で1位を取るか

### 主戦場: サロン × AI電話（`salon-ai-phone` クラスタ）

「美容室 電話 自動化」「施術中 電話 対応」「一人サロン 電話 対応」など。

- 競合が弱い。大手SaaSはこの粒度の記事を書かない
- 検索している人がそのまま見込み客（MOYO Call が解ける課題そのもの）
- 既存11記事の軸と一致しているので、**新規作成より既存の拡充が効く**

ここは**取れる**。1位を狙うのはこのクラスタ。

### 面を広げる: AI電話代行 全般（`ai-phone-general` クラスタ）

「AI電話代行 比較」「AI電話代行 料金 相場」など。

検索volumeは大きいが、Salesforce・比較メディア・アフィリエイトサイトが上位を固めている。
**短期で1位は取れない**。ここは「比較・料金・仕組み」の網羅性で3〜10位に入り、
サロンクラスタから流入と被リンクを育ててから押し上げる中期戦。

### 追わないもの

- **単独の「MOYO」**: 日本では既に衣料・文具の MOYO ブランドが EC で面を取っている。
  異業種なので実害は無いが、この語で1位を取りに行くのは費用対効果が悪い。
  狙うなら「MOYO 電話」「MOYO サロン」「MOYO Call」の複合語。
- **地域名の量産**（「美容室 電話代行 渋谷」等）: 中身の無いページが量産されるだけで、
  現在の記事密度では逆効果。主戦場で1位を取ってから検討する。

## ドメインをどうするか（提案）

**結論: 移すなら今。ただし「ブランドを MOYO で確定させる」判断が先。**

判断材料:

| | 内容 |
|---|---|
| 失うもの | ほぼ無い。callmintai.com は主要KWで圏外＝積み上がったドメイン評価が事実上ゼロ。移行コストが最も安いのが今で、記事が増えるほど高くなる |
| 得るもの | ブランドとドメインの一致。今は LP に「MOYO Call」と書いてあるのに URL が callmintai.com で、指名検索・名刺・口頭説明のすべてで一段説明が要る |
| 巻き込む範囲 | LP だけでは済まない。cms（`app.callmintai.com`）、メール、Twilio、Stripe、Search Console のプロパティ再登録。手順書は `callmint-cms/docs/2026-08-18-moyo-domain-migration-plan.md` にある |
| やらない場合のコスト | 「Callmint」と「MOYO」の二重ブランドが恒久化する。SEO 上は致命傷ではないが、指名検索が育たない |

**推奨する進め方**:

1. まず **ブランド名を MOYO で確定**する（ここが決まらないうちは動かさない）
2. 確定したら `moyo` を含むドメインを取得し、**LP を先に移す**（cms は後でよい）
3. 旧URL → 新URL を **1対1で 301**。トップにまとめてリダイレクトしない（評価が渡らない）
4. Search Console で新旧プロパティを両方登録し、**アドレス変更ツール**を使う
5. `sitemap.xml` / `canonical` / `llms.txt` / 構造化データの `@id` を一斉に書き換える
   （`tools/seo_fix.py` の `SITE` 定数を変えれば sitemap と robots は自動追従する）
6. 旧ドメインは最低2年維持する。切ると 301 が消えて評価が落ちる

**移行を保留するなら**: それはそれで構わない。その場合は `seo/keywords.json` の
`brand` クラスタの優先度を下げ、サロンクラスタに全振りする。
中途半端に両ブランドで記事を書き分けるのが一番損。

## 1位までの道筋

| 段階 | やること | 目安 |
|---|---|---|
| 済 | 技術SEOの欠陥を潰す（画像29MB・meta欠落・構造化データ・sitemap） | — |
| **次** | **Search Console を接続する**（`GSC_SERVICE_ACCOUNT_JSON`）。これが無いと順位が見えず、エージェントは自サイトの欠陥しか見られない | 即 |
| 1〜2ヶ月 | 既存11記事を1本ずつ 6,000〜10,000字へ拡充（日次エージェントが1日1本） | 自動 |
| 2〜4ヶ月 | サロンクラスタの未作成6記事を作る | 自動 |
| 3ヶ月〜 | 被リンク。ここだけは自動化できない（下記） | 手動 |

### 自動化できない打ち手（人間がやる）

順位の上限を決めるのは最終的に**外部からの評価**で、これはコードでは作れない。

- **導入事例を増やす**。現在1件（BONHEUR HAIR）。事例ページは被リンクとE-E-A-Tの両方に効く
- **サロン向けメディア・美容商材の展示会・地域の美容組合**からの掲載/リンク
- **Google ビジネスプロフィール**（合同会社8ZERO として）
- note / X で書いている内容から、LP の該当記事へ導線を張る
  （`callmint`リポジトリの content-shark が週次で note 記事を作っている。
  そこから LP へリンクしていないのは機会損失）
- 「MOYO Call」で**実際に電話をかけたレビュー**を書いてもらう
